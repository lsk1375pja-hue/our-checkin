# 우리의 체크인 — GitHub Pages 시제품

## 지금 들어 있는 기능
- 개인 기기에서 오늘의 할 일 추가 및 체크
- 완료 항목 기준 달성률(%) 계산
- 오전 9시 이후 계획 수정 잠금(기기 시간 기준)
- 친구 현황 화면의 시각적 예시

## 중요: 현재는 시제품입니다
이 버전은 데이터를 각 브라우저의 localStorage에만 저장합니다.
따라서 친구와 자동으로 동기화되지 않으며, 친구 목표의 실제 서버 측 비공개 권한도 없습니다.
공유 서비스로 사용하기 전에는 로그인, 데이터베이스, 서버 측 권한 정책을 추가해야 합니다.
오전 9시 잠금도 실제 서비스에서는 서버 시간을 기준으로 검증해야 합니다.

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `our-checkin`
2. 저장소에 이 `index.html` 파일을 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다.
6. 배포가 완료되면 Pages 화면에 표시되는 사이트 링크로 접속합니다.

## 실제 친구 공유 버전으로 확장하려면
- Supabase Auth로 사용자 로그인
- Supabase 데이터베이스에 날짜별 개인 목표 저장
- Row Level Security(RLS)로 목표 제목과 체크 상태를 본인만 읽고 수정할 수 있게 제한
- 친구에게는 달성률/완료 여부 요약만 반환
- 오전 9시 이후 목표 추가·수정은 서버 시간으로 거부
